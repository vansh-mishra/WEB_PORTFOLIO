# Vansh Mishra — Portfolio Website

A responsive portfolio built with HTML, CSS and JavaScript. The visual system uses warm ivory, charcoal, muted olive and terracotta, with restrained motion and a light/dark theme.

## Pages and sections

- `index.html` — About, technical skills, seven projects, internship and hackathon experience, three separate credential entries, and contact details
- `education.html` — A separate page for academic qualifications, opened from the Education link in the main navigation

## UI interactions

- Light/dark theme toggle with a saved visitor preference
- Smooth section reveals with staggered entrances
- Hover feedback on navigation, project illustrations, skill cards, buttons and social links
- Pointer-aware highlights on selected desktop surfaces
- Reading-progress indicator and floating back-to-top control
- Active navigation state and mobile navigation menu
- Reduced-motion support for visitors who disable animation

## Run locally

1. Extract the ZIP file.
2. Keep `index.html`, `education.html`, `styles.css`, `script.js` and the `assets` folder together.
3. Open `index.html` in a browser. For the best development experience, use the VS Code Live Server extension.

No build step or JavaScript framework is required. Google Fonts are loaded online; the page falls back to Georgia and system sans-serif fonts when unavailable.

## Publish online

Upload the complete `vansh-portfolio` folder to GitHub Pages, Netlify or Vercel. Do not upload only the HTML files; the stylesheet, script and face-scan illustration are also required.
